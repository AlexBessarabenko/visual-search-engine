# План: Мультимодальный поиск изображений по тексту

## Архитектура

**Цель:** Система поиска изображений по текстовым запросам с использованием мультимодальных эмбеддингов.

**Трек:** A — Поиск изображений по тексту

### Технический стек
- **Модель (основная):** `jinaai/jina-embeddings-v5-omni-nano` (modality=vision, truncate_dim=256) — 1.04B параметров, оптимизирована под CPU через truncation
- **Модель (бейслайн):** `openai/clip-vit-base-patch32` — 150M параметров, классический CLIP
- **Датасет:** `google-research-datasets/conceptual_captions` — 5000 примеров (URL изображений + подписи)
- **Векторная БД:** FAISS (CPU-версия) с Flat-индексом + HNSW для сравнения
- **Метрики:** Precision@k, Recall@k, mAP, среднее время поиска
- **Интерфейс:** Streamlit (опционально) + Jupyter Notebook с визуализацией
- **Контейнеризация:** Docker + docker-compose

### Оптимизации под ресурсы (i5-10310U, 16GB RAM, CPU)
1. `modality="vision"` — загружаем только vision + text towers, без audio
2. `truncate_dim=256` — уменьшаем размерность с 768 до 256 (экономия памяти и скорости)
3. `torch_dtype=torch.float32` (CPU не поддерживает bf16)
4. Батчинг при индексации (batch_size=8 для Jina, 32 для CLIP)
5. Кэширование эмбеддингов на диск
6. FAISS Flat-индекс для 5000 точек (достаточно быстрый, не требует обучения)

### Этапы выполнения

**Stage 1 — Подготовка данных**
- Загрузка conceptual_captions (5000 примеров)
- Скачивание изображений по URL
- Фильтрация битых ссылок

**Stage 2 — Создание эмбеддингов**
- Эмбеддинги изображений через Jina v5-omni-nano (vision)
- Эмбеддинги изображений через CLIP (бейслайн)
- Кэширование на диск

**Stage 3 — Индексация**
- Построение FAISS Flat-индекса
- Построение FAISS HNSW-индекса (для сравнения скорости)
- Сохранение индексов

**Stage 4 — Поиск и оценка**
- Текстовые запросы: "собака на пляже", "красный автомобиль", "люди играют в футбол"
- Измерение Precision@5, Recall@5, mAP
- Сравнение Jina vs CLIP
- Сравнение Flat vs HNSW по скорости

**Stage 5 — Документация и деплой**
- README с отчётом
- Docker-контейнер
- Пуш на GitHub
